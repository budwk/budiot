- title: Lightweight Architecture
  details: Built on the self-developed open-source BudWk framework, with a clear structure, simple code, and low learning curve

  details: Horizontally scalable architecture, supporting millions of device connections and hundreds of thousands of concurrent data operations
- title: Easy to Extend
  details: Utilizes RocketMQ, MongoDB time series collections, Redis cache, and supports alternative message middleware like RabbitMQ, Kafka, and time series databases like TDEngine, ClickHouse
- title: Multi-Protocol Support
  details: Supports various network protocols including TCP, UDP, MQTT, HTTP, and integration with IoT platforms like AEP, OneNet, and custom device protocol development
- title: Flexible Deployment
  details: Developed with a front-end and back-end separation model, the Java microservice backend supports single-machine, cluster, and containerized deployment options
- title: Cost-Effective
  details: Particularly suitable for managing hundreds of thousands to millions of devices, with great flexibility for customized development of various functions
